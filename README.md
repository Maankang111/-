# 价格行为学习系统

自用工具，数据存本地文件，可以用 git 版本管理。

## 怎么启动

推荐直接用完整路径，在哪个目录执行都行，不用先 cd：

```
"D:\python3.11.1\python.exe" "D:\workBuddy任务\2026-10-22-10-12-03\pa_server.py"
```

启动后会自动打开浏览器，地址 `http://127.0.0.1:8765/`。黑色窗口别关，关掉服务就停了，按 Ctrl+C 结束。

如果在同一目录下，也可以短一点：`python pa_server.py`，前提是 `python` 命令本身能用。

## 启动报错对照

脚本会先打印环境信息，包括 Python 版本、工作目录、脚本目录。看到错先看这三行。

| 报错内容 | 原因 | 怎么办 |
| --- | --- | --- |
| can't open file 'pa_server.py' | 当前目录不是这个文件夹 | 改用上面那条完整路径的命令 |
| 'python' 不是内部或外部命令 | 系统 PATH 里没有 python | 用完整路径，别只写 python |
| [WinError 10048] 端口被占用 | 8765 被别的程序占了 | 换端口：`...pa_server.py 9000` |
| 启动失败：数据目录不可写 | 权限问题 | 把整个文件夹换到有写权限的位置 |
| 启动失败：找不到 html | 两个文件没放一起 | 确认 html 和 py 在同一文件夹 |
| 窗口一闪就消失 | 双击运行的 | 改成在命令行里执行，能看见错误 |
| 浏览器没自动打开 | 默认浏览器设置问题 | 手动打开 `http://127.0.0.1:8765/` |

## 怎么提交 git

页面右上角有两个按钮：

| 按钮 | 做什么 |
| --- | --- |
| 提交到 git | 只在本地存档，执行 `git add -A` 加 `git commit`，不联网 |
| 同步到远程 | 先提交，再推送到 GitHub，一键完成 |

平时填完当天的内容，点一次「同步到远程」就行。

## 传到自己的 git（不动公司配置）

机器上如果登着公司的 git，推到自己的仓库要做三件事：身份用仓库级、远程指向自己的、认证用独立凭据。

### 一步到位

先在 git 网站（GitHub、Gitee 或自建）建一个空仓库，**不要勾选自动生成 README**，拿到地址后运行：

```
"D:\python3.11.1\python.exe" "D:\workBuddy任务\2026-10-22-10-12-03\setup_personal_git.py"
```

脚本会问你要仓库地址，然后自动做这些：

| 动作 | 说明 |
| --- | --- |
| git init | 如果还不是仓库 |
| 设置仓库级身份 | 只对这个仓库生效，不改全局 |
| 写 .gitignore | 忽略缓存和临时文件 |
| 首次提交 | 提交信息是「初始化：价格行为学习系统」 |
| 设置 origin | 指向你给的地址，重复运行会替换而不是叠加 |

最后它会打印你该执行的 push 命令。

### 认证两条路，选一条

| 方式 | 适合 | 要做的事 |
| --- | --- | --- |
| https 地址 | 图省事 | 推送时弹窗输账号。GitHub 不能用登录密码，要去 Settings 生成 Personal Access Token 当密码，权限勾 repo。Gitee 可以直接用密码或私人令牌 |
| ssh 地址 | 长期用，不想管 token 过期 | 跑脚本时加 `--ssh`，它会生成 `~/.ssh/id_ed25519_personal` 并把公钥打印出来，你把公钥贴到网站的 SSH Keys 里 |

用 ssh 的话，remote 地址要写成 `git@github.com:用户名/仓库.git` 或 `git@gitee.com:用户名/仓库.git`。

### 为什么不会和公司的混

提交身份、远程地址都是仓库级配置，只在这个文件夹生效。认证凭据按域名分开存，公司内网地址和你自己的仓库地址不是同一个域名，不会互相串用。

## 图片怎么传

在「今日标图记录」那一块，三种方式都行：

| 方式 | 怎么做 |
| --- | --- |
| 选文件 | 点「点这里选文件」，可以一次选多张 |
| 拖进来 | 把图片文件直接拖到虚线框里 |
| 粘贴 | 截图后按 Ctrl+V，剪贴板里的图会自动加进去 |

### 存在哪里

按日期分文件夹，一天一个：

```
data\img\2026-10-22\2026-10-22_1114_通道_054.png
data\img\2026-10-22\2026-10-22_1130_区间_207.png
data\img\2026-10-23\2026-10-23_0921_突破_318.png
```

文件名格式是「日期_时分_当时选的状态_毫秒」。所以看文件名就知道是哪天、几点、什么状态标的，不打开 `records.json` 也能认出来。

页面上「今日标图记录」里有个「打开图片文件夹」按钮，点一下直接在资源管理器里打开当天的目录。旁边一行字写着完整路径。

一条记录可以配多张图。填完字段点「保存这张」，图和文字一起归档。点缩略图能看大图。

注意：图片只有在服务模式下才会存成文件。直接双击 HTML 打开时，图片会被压缩后塞进浏览器存储，容易存满，看图这件事建议一律走 localhost。

### git 里中文文件名

文件名带中文（通道、区间）是为了你一眼看得懂。git 默认会把中文显示成 `\344\270\255` 这种转义，看着乱。执行一次这个就好：

```
git config core.quotepath false
```

## 两种打开方式的区别

| 打开方式 | 数据存哪 | 能不能 git |
| --- | --- | --- |
| 跑 pa_server.py 后访问 localhost | data/records.json | 能 |
| 直接双击 PA学习系统.html | 浏览器里 | 不能，但能「导出备份」成 json |

两种方式的数据不互通。想长期用就走第一种，把浏览器收藏夹里存 localhost 那个地址。
